# Pulse — мобильное приложение (iOS)

Нативное SwiftUI-приложение для киберспортсменов и staff: сон, фитнес, экранное время, питание, тесты (когнитивная батарея, настроение и энергия, колесо баланса), статистика с корреляциями, календарь и аналитика игроков для staff. Дизайн повторяет присланные макеты (тёмная тема, сине-голубой акцент).

## Режимы работы (версия 1.0)

- **Свой аккаунт** — регистрация и вход по email/паролю **на телефоне** (сервера пока нет): пароль хранится как PBKDF2-хеш в Keychain, данные — в папке аккаунта (`Application Support/Pulse/accounts/<id>/`). Новый аккаунт начинает с пустых экранов, без выдуманных чисел. Профиль → «Удалить аккаунт» удаляет всё.
- **Демо** — кнопка «Посмотреть демо» на экране входа (Игрок / Solo / Стафф): отдельная папка с примерами данных, не смешивается с личными записями.
- **Сервер** — клиент API уже в проекте (`Pulse/Core/API`, `RemoteAuthService`, `SyncEngine`), включается в `AppConfig.swift`. Контракт для бэкенда — [`docs/API.md`](docs/API.md). Публикация — [`docs/RELEASE.md`](docs/RELEASE.md).

В версии 1.0 без сервера: стафф доступен только в демо; еда — фото + ручной ввод (AI-распознавание появится с сервером); экранное время — ручной ввод за день (автосбор требует разрешения Apple Family Controls).

## Установка на свой iPhone (демо без сервера)

Нужны: Mac с Xcode 16+, iPhone на iOS 17+, кабель и Apple ID (подойдёт бесплатный).

1. **Xcode → Settings → Accounts → «+» → Apple ID** — войдите своим Apple ID. Появится команда «Personal Team».
2. Подключите iPhone кабелем, на телефоне нажмите **«Доверять этому компьютеру»**.
3. На iPhone включите **Настройки → Конфиденциальность и безопасность → Режим разработчика** (телефон перезагрузится, подтвердите включение).
4. Откройте `Pulse.xcodeproj` → в списке слева проект **Pulse** → таргет **Pulse** → вкладка **Signing & Capabilities**:
   - оставьте галочку **Automatically manage signing**;
   - в **Team** выберите свою команду (Personal Team);
   - если Xcode пишет, что Bundle Identifier занят, замените `com.pulsecrm.mvp` на любой свой, например `com.<ваше_имя>.pulse`.
5. Вверху Xcode выберите свой iPhone вместо симулятора и нажмите **⌘R** (Run).
6. При первом запуске iPhone попросит доверять разработчику: **Настройки → Основные → VPN и управление устройством → ваш Apple ID → Доверять**. Затем снова ⌘R или откройте приложение с экрана «Домой».

Ограничения бесплатного аккаунта: приложение работает 7 дней, потом повторите ⌘R из Xcode (данные сохранятся). Платный Apple Developer Program ($99/год) даёт сборку на год и TestFlight — установку другим людям по ссылке.

### Сценарий показа

1. Вход: «Посмотреть демо» → Игрок / Solo / Стафф. Для своего аккаунта — «Зарегистрироваться».
2. **Профиль → Демо-режим**: смена роли без выхода, тестовые пуши («Игровой тест до тренировки», «Напоминание о событии» — приходят через 5 секунд, можно свернуть приложение), «Сбросить демо-данные» перед следующим показом.
3. Регистрация (Соло / Командный доступ → Я игрок) работает на телефоне; код команды сохраняется в профиле и будет проверен сервером. Регистрация стаффа откроется с сервером.
4. Фото еды для стаффа: войдите игроком, сфотографируйте еду: «Состояние» → «Здоровье» → карточка «Питание» (или «+» → «Фото еды»), затем в «Демо-режиме» переключитесь на «Стафф» → вкладка «Игроки» → «Питание» — снимок появится в ленте. Еда соло-игроков стаффу не показывается.
5. Дневник CS2 (вкладка «Дневник» в нижней панели): у соло — личный, у игрока команды — личный + командный (переключатель «Показать команде»), стафф видит только командные записи.
6. Фото еды: в демо — «анализ» (заглушка, блюдо из списка); в своём аккаунте — фото + ручной ввод калорий и БЖУ, без выдуманного распознавания.
7. Графики: удерживайте палец на любом графике и ведите — видно значение выбранного дня (как в биржевых приложениях). На колесе баланса так же выбирается сфера.
8. Трекинг сна: «Сон» → «Начать сон» → заблокируйте телефон — на экране блокировки таймер (Live Activity) с кнопкой «Проснулся». В «Демо-режиме» есть пуш «Скоро отбой» с кнопкой «Начать сон» прямо в уведомлении.
9. Уведомления (колокольчик): карточки смахиваются пальцем влево или вправо.
10. Фитнес: «Состояние» → «Здоровье» → «Фитнес» → «Подключить» — данные берутся из Apple Health (только чтение). Меню «…» → «Показывать демо-данные» возвращает демо для показа.
11. Сон из Apple Health: после подключения «Здоровья» последняя ночь (фазы, пульс, HRV, дыхание, SpO₂) и история сна берутся из часов/трекера; без часов — ручной трекинг.
12. Нагрузка и восстановление: «Фитнес» → «Нагрузка» (тяжесть 1–10 × минуты, ACWR 0,8–1,3) и «Восстановление» 0–100 (HRV, сон, пульс покоя, самочувствие). Нажми на тренировку, чтобы оценить тяжесть. Стафф видит нагрузку в карточке игрока.
13. Faceit: «Состояние» → «Игра» → «Подключить» — ник/ссылка и API-ключ (developers.faceit.com → App Studio, ключ хранится в Keychain). Подтягиваются ELO, уровень, место в регионе, статистика за всё время и по картам, последние 100 матчей с хедшотами, входами, клатчами, гранатами. История ELO копится с момента подключения (Data API отдаёт только текущее значение).
14. Итоги недели: «Сегодня» → «Неделя» (или пуш в воскресенье в 19:00). Оценка недели 0–100 и сравнение с прошлой неделей по сну, тренировкам, нагрузке, экрану, питанию, настроению, тестам и игре; цели недели и советы на следующую. Стрелками можно листать недели, «Поделиться» отправляет текст. Стафф видит «Сводку команды»: готовность, сон, матчи и победы, лидеры роста, зона риска и таблицу игроков.
15. Анкета игрока: при первом входе — цели (до 3), «Что ты за игрок» (роль, уровень, опыт, часы, время игры, мотивация) и тест «Игровой характер» (24 утверждения, 6 черт: хладнокровие, контроль тильта, концентрация, командность, лидерство, дисциплина → ведущая черта, сильные стороны, зоны роста, советы). Профиль → «Игровой профиль»: перепройти тест, изменить анкету. Стафф видит ведущую черту в составе и «Профиль игрока» + «Как работать с игроком» в карточке. Цели из анкеты поднимают нужные советы в «Итогах недели».

## Запуск

1. Откройте `Pulse.xcodeproj` в Xcode 16+ (проверено на Xcode 26.5).
2. Выберите схему **Pulse** и симулятор iPhone (например, iPhone 17 Pro) → `⌘R`.
3. Для запуска на устройстве выберите свою команду в *Signing & Capabilities*.

Тесты: `⌘U` или

```bash
xcodebuild test -project Pulse.xcodeproj -scheme Pulse -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```

### Демо-аккаунты

Открываются кнопкой «Посмотреть демо» на экране входа (или вручную, пароль `pulse2026`).

| E-mail | Роль | Тариф |
|---|---|---|
| `player@pulse.app` | Командный игрок | PRO |
| `solo@pulse.app` | Solo игрок | FREE (история/тренд тестов заблюрены) |
| `staff@pulse.app` | Staff | PRO (раздел «Игроки», тэги в календаре) |

Эти адреса нельзя занять при регистрации своего аккаунта.

### Версии приложения по роли

- **Игрок (Solo / командный):** Сегодня · Состояние · Питание · Профиль. У командного игрока есть «Раскидки и скрипты» в «Состоянии».
- **Staff:** без кнопки «+» — пять вкладок: Сегодня (готовность команды, кто требует внимания) · Игроки (состав и питание с фото) · Аналитика (дашборд команды и корреляции) · База знаний (раскидки, скрипты, заметки) · Профиль. Календарь — в верхней панели.
- Статус профиля показан бейджем в верхней панели и в профиле.

### Debug: открыть экран сразу

`-PulseNoPrompts` — не показывать системные запросы разрешений, `-PulseScrollAnchor center|bottom` — открыть экран прокрученным (для скриншотов на маленьких iPhone), `-PulseDemoRole fresh` — войти в новый пустой локальный аккаунт.

```bash
xcrun simctl launch booted com.pulsecrm.mvp -PulseDemoRole staff -PulseRoute analytics
```

`-PulseDemoRole staff|player|solo` сразу входит нужным демо-аккаунтом.

Маршруты: `today`, `players`, `analytics`, `lineups`, `teamAnalytics`, `teamCorrelations`, `sleep`, `recovery`, `fitness`, `fitnessWeek`, `screen`, `screenApps`, `nutrition`, `nutritionHistory`, `tests`, `cognitive`, `mood`, `balance`, `gameTests`, `stats`, `calendar`, `players`, `profile`, `weekly`, `portrait`.

## Архитектура

```
Pulse/
├── App/            точка входа, DI (AppDependencies), навигация, таб-бар, App Intents, уведомления
├── DesignSystem/   токены (Theme), карточки, хедеры, кольца, бары, радар-диаграмма
├── Core/           форматирование (ru), JSON-хранилище, статистика (Пирсон)
├── Models/         доменные модели и валидаторы (Auth, Event)
├── Stores/         @Observable-сторы + протоколы сервисов (AuthService, FoodAnalyzing) + демо-данные
└── Features/       экраны по модулям ТЗ
PulseWidgets/       расширение WidgetKit: Live Activity сна (экран блокировки, Dynamic Island)
Shared/             код, общий для приложения и расширения (атрибуты Live Activity, интент «Проснулся»)
PulseTests/         unit-тесты (Swift Testing)
```

- **SwiftUI + Observation**, iOS 17+, без сторонних зависимостей; графики — Swift Charts.
- Данные хранятся локально (JSON в Application Support). Сервисы закрыты протоколами — для подключения бэкенда веб-версии достаточно реализовать `AuthService` и аналогичные репозитории, экраны менять не нужно.

## Ограничения MVP и следующие шаги

1. **Бэкенд.** Сейчас mock-авторизация и локальные данные. Нужна спецификация API веб-версии (эндпоинты, роли, тарифы).
2. **AI-калорийность.** `MockFoodAnalyzer` возвращает правдоподобное блюдо. Реальная интеграция — через эндпоинт вашего бэкенда, который вызывает vision-модель (ключ API не должен храниться в приложении).
3. **Экранное время.** Реальные данные требуют entitlement `FamilyControls` (заявка в Apple) и расширения DeviceActivity Report. До одобрения показываются демо-данные; при выключенном доступе — Empty State из ТЗ.
4. **Фитнес / фазы сна / пульс.** Демо-данные; следующий шаг — HealthKit (шаги, тренировки, сон, пульс, HRV, SpO₂).
5. **Lock Screen.** Сейчас App Intent (Команды, кнопка Action). Отдельный виджет / Control Center control потребует Widget Extension.
6. **Покрытие тестами:** логика (валидация, сторы, статистика) — 65–100 %, UI-слой не покрыт; общее покрытие ~22 %. Для 80 % нужны UI-тесты основных сценариев.
