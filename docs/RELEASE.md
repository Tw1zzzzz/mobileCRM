# Публикация Pulse 1.0 (данные на телефоне)

## Что уже готово в проекте

- Локальные аккаунты: регистрация/вход по email и паролю (PBKDF2-хеш в Keychain), удаление аккаунта со всеми данными.
- Данные каждого аккаунта в своей папке; демо — отдельный аккаунт («Посмотреть демо» на экране входа).
- Новый пользователь начинает с пустых экранов, без выдуманных чисел. Еда — фото + ручной ввод
  (без поддельного «распознавания»), экранное время — ручной ввод, стафф — только в демо.
- Apple Health (только чтение), Faceit со своим ключом, локальные уведомления, Live Activity сна.
- `PrivacyInfo.xcprivacy`, `ITSAppUsesNonExemptEncryption = NO`, категория «Здоровье и фитнес», версия 1.0.0.
- Тексты политики и соглашения в приложении и в `docs/privacy-policy.md`, `docs/terms.md`
  (черновики — **показать юристу**, вписать реальный email поддержки).

## Шаги, которые нужно сделать вам

1. **Apple Developer Program** ($99/год) — без него нельзя TestFlight и App Store.
2. **Bundle ID.** Сейчас `com.pulsecrm.mvp`; после первой загрузки его нельзя поменять.
   Если нужен другой (например, `com.pulse.app`) — скажите до загрузки, я поменяю его в проекте
   вместе с `com.pulsecrm.mvp.widgets` и `com.pulsecrm.mvp.tests`.
3. **Xcode → Signing & Capabilities** таргетов Pulse и PulseWidgets: выбрать команду организации.
   Capability HealthKit уже включена (файл `Pulse.entitlements`).
4. **App Store Connect → Новое приложение**: имя, язык — русский, SKU, выбрать Bundle ID.
5. **Политика конфиденциальности** — разместить `docs/privacy-policy.md` на сайте и вставить ссылку
   (обязательно для приложений с HealthKit).
6. **App Privacy (анкета о данных):** «Data Not Collected» — все данные остаются на устройстве,
   Faceit вызывается по ключу пользователя напрямую. Когда подключим сервер, анкету обновим.
7. **Возрастной рейтинг:** 4+ (нет нежелательного контента).
8. **Скриншоты:** 6.9" (1320×2868) и 6.5" (1284×2778) — можно снять в симуляторе в демо-аккаунте.
9. **Сборка:** Xcode → Product → Archive → Distribute App → App Store Connect → Upload.
10. **TestFlight:** добавить тестировщиков — установка по ссылке без кабеля и без 7-дневного срока.
11. **Заметки для App Review** (поле Review Notes):

    > Аккаунт можно создать на экране регистрации (данные хранятся только на устройстве).
    > Для быстрого просмотра всех экранов — кнопка «Посмотреть демо» на экране входа.
    > Apple Health используется только для чтения (сон, шаги, пульс, тренировки) и только после согласия.
    > Pulse — не медицинское изделие.

## После релиза — подключение сервера

Контракт API для бэкенда — `docs/API.md`. Когда сервер готов: `AppConfig.backend = .remote(<URL>)`,
обновить политику конфиденциальности и анкету App Privacy, затем новая версия в App Store.
