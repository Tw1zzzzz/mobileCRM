# Политика конфиденциальности Pulse

Редакция от 14 октября 2026.

1. Какие данные обрабатывает Pulse
• Данные аккаунта: имя, email, роль, ссылка на профиль Faceit, код команды.
• Записи, которые вы вносите: сон, питание и фото блюд, настроение и энергия, колесо баланса, результаты тестов, анкета игрока (цели, роль, уровень) и самооценка «Игровой характер», тренировки, экранное время, события календаря, дневник CS2, цели.
• Данные Apple Health — только после вашего разрешения и только для чтения: шаги, дистанция, активная энергия, минуты упражнений, пульс, пульс покоя, вариабельность пульса, дыхание, кислород в крови, сон, тренировки, вес и состав тела.
• Игровые данные Faceit — только если вы подключили Faceit своим API-ключом.

2. Где хранятся данные
Все данные хранятся только на вашем устройстве, в зашифрованном хранилище приложения. Пароль не сохраняется: хранится только его криптографический хеш в Keychain. Мы не передаём ваши данные на свои серверы, не используем рекламу и трекинг, не продаём и не передаём данные третьим лицам.

3. Apple Health
Данные Apple Health используются только для показа статистики внутри приложения. Они не передаются третьим лицам, не используются для рекламы и не сохраняются в iCloud. Доступ можно отозвать в Настройки → Здоровье → Доступ к данным → Pulse.

4. Faceit
Если вы подключили Faceit, приложение запрашивает у Faceit Data API публичную статистику по нику, используя ваш API-ключ. Ключ хранится в Keychain вашего устройства.

5. Уведомления
Напоминания о событиях, тестах и сне создаются на устройстве и не требуют передачи данных.

6. Удаление данных
Профиль → «Удалить аккаунт» удаляет аккаунт и все его данные с устройства безвозвратно. Удаление приложения также удаляет все данные.

7. Будущая синхронизация
Когда появится сервер Pulse для синхронизации с веб-версией и командой, мы обновим эту политику и попросим отдельного согласия до передачи данных.

8. Контакты
По вопросам обработки данных: support@pulse.app (укажите актуальный адрес перед публикацией).
